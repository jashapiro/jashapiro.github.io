# Source Code Pro

The site's code font, self-hosted.

- `web/*.woff2`: Latin and Latin Extended subsets of weights 400 and 700 from the Fontsource npm package `@fontsource/source-code-pro` 5.3.0, unmodified. Used by the website through the `@font-face` rules in `css/fonts.scss`.
- License: SIL Open Font License 1.1 (`LICENSE.txt`, from <https://github.com/adobe-fonts/source-code-pro>), with Reserved Font Name "Source".
